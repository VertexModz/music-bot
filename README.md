# 🎵 บอทเพลง Discord

เล่นเพลงจาก YouTube (สำรองด้วย SoundCloud อัตโนมัติ) รันบน Render (free tier) ได้แบบไม่ต้องต่ออายุเอง

## เริ่มใช้งาน (Render)

1. push โปรเจกต์นี้ขึ้น GitHub repo
2. สร้าง **Web Service** บน Render แล้วผูกกับ repo — Build Command: `npm install`, Start Command: `npm start`
3. ใส่ค่าใน Environment Variables: `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`
4. หลัง deploy สำเร็จครั้งแรก เปิด Shell ของ Render (หรือรันในเครื่องตัวเองครั้งเดียว) แล้วรัน `node deploy-commands.js` เพื่อลงทะเบียนคำสั่ง (ทำอีกครั้งเมื่อคำสั่งเปลี่ยน)
5. ตั้ง cron-job.org หรือ UptimeRobot ให้ ping `https://<ชื่อบอท>.onrender.com/health` ทุก 10-14 นาที กัน Render สั่ง sleep (ดูหัวข้อ "โฮสต์ตลอด 24 ชม." ด้านล่าง)

Node 20 ขึ้นไปใช้ได้ (บอทโหลด JS runtime ที่ yt-dlp ต้องใช้มาให้เอง)

ตอนบอทเริ่ม Console จะแสดง **ลิงก์เชิญบอท** และผลตรวจระบบ เช่น `✅ YouTube ใช้ได้`
บอทโหลดและอัปเดต yt-dlp ให้เอง (ตอนเริ่ม และทุก 12 ชั่วโมง) ไม่ต้องติดตั้งอะไรเพิ่ม

### อัปเกรดจาก v2
แทนที่ไฟล์ทั้งหมดด้วยชุดนี้ แล้วรัน `node deploy-commands.js` อีกครั้ง (มีตัวเลือกคำสั่งใหม่) จากนั้น `node index.js` — ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## ใช้ยังไง

เข้าห้องเสียง แล้วพิมพ์ `/play` ตามด้วยชื่อเพลงหรือลิงก์ YouTube / SoundCloud / เพลย์ลิสต์
ตอนพิมพ์จะมีคำแนะนำขึ้นให้เลือก และ**กดปุ่มใต้การ์ดเพลง**แทนการพิมพ์คำสั่งได้เลย

| ปุ่ม | ทำอะไร |
|---|---|
| ⏸️ / ▶️ | หยุดชั่วคราว / เล่นต่อ |
| ⏭️ | ข้ามเพลง |
| ⏹️ | หยุดและออกจากห้อง |
| 🔁 / 🔂 | สลับโหมดวน: ปิด → เพลงเดียว → ทั้งคิว |
| 🔀 | สลับคิว |
| 🔉 🔊 | ลด / เพิ่มเสียงทีละ 10% |
| 📜 | ดูคิว |

## คำสั่ง

`/play` `/pause` `/resume` `/skip` `/skipto` `/queue` `/nowplaying`
`/shuffle` `/remove` `/clear` `/loop` `/volume` `/stay247` `/stop` `/help`

- `/play` มีตัวเลือก **แทรกคิว** = ให้เล่นต่อจากเพลงนี้เลย
- `/queue` แบ่งหน้า กด ◀ ▶ ได้ เลขลำดับ `1` = เพลงถัดไป
- `/remove` และ `/skipto` เลือกเพลงจากชื่อได้เลย (หรือพิมพ์เลขลำดับจาก `/queue`)
- `/volume` ไม่ใส่ตัวเลข = ดูระดับเสียงตอนนี้
- ต้องอยู่ห้องเสียงเดียวกับบอทถึงจะสั่งควบคุมได้ (คนที่มีสิทธิ์ Manage Server สั่งได้ทุกที่)

## ทำไมเร็ว

- ต่อห้องเสียงไปพร้อมกับค้นหาเพลง และโหลดเสียงระหว่างรอห้องเสียงพร้อม
- **โหลดเพลงถัดไปไว้ล่วงหน้า** ตอนเพลงปัจจุบันเหลือ ~20 วินาที ต่อเพลงได้แทบทันที (ปิดได้ด้วย `PREFETCH=off`)
- จำผลค้นหา/ข้อมูลเพลงไว้ 10 นาที ค้นซ้ำได้ทันที
- อัปเดต yt-dlp เบื้องหลัง เพลงแรกหลังบอทรีสตาร์ตไม่ต้องรอ

## ถ้าเล่นไม่ได้

บอทจะบอกสาเหตุในแชท และมีรายละเอียดใน Console

- **"YouTube บล็อกเซิร์ฟเวอร์นี้"**: บาง IP ของโฮสต์ฟรี (Render รวมถึงเจ้าอื่นๆ) ที่ YouTube ไม่ค่อยไว้ใจ
  บอทจะสลับไปเล่นจาก SoundCloud ให้เอง ถ้าอยากได้ YouTube ให้ใส่ cookies:
  1. ติดตั้งส่วนขยาย "Get cookies.txt LOCALLY" ในเบราว์เซอร์ที่ล็อกอิน YouTube (แนะนำใช้บัญชีสำรอง)
  2. เปิด youtube.com แล้วส่งออก cookies เป็นไฟล์ `cookies.txt`
  3. อัปโหลดไฟล์ไว้ในโฟลเดอร์โปรเจกต์ (ข้างๆ `index.js`) แล้วรันบอทใหม่
- **เข้าห้องเสียงได้แต่ไม่มีเสียง**: ตรวจว่าใช้ `@discordjs/voice` 0.19 ขึ้นไป (`npm install` ใหม่)
- **"YouTube ปฏิเสธคำขอ" / "The page needs to be reloaded"**: cookies หมดอายุหรือถูกเพิกถอน ให้ส่งออก cookies ใหม่ (หรือลบ `cookies.txt` ทิ้ง บอทจะลองแบบไม่ใช้ cookies ให้เองอัตโนมัติ)
- **คำแนะนำตอนพิมพ์ไม่ขึ้น**: ไม่กระทบการเล่นเพลง แค่พิมพ์ชื่อเพลงเองแล้วกด Enter ตามปกติ
- **บอทไม่ส่งการ์ดเพลง**: ตรวจสิทธิ์ของบอทในห้องแชท (ส่งข้อความ + ฝังลิงก์) — ใช้ลิงก์เชิญที่ Console แสดงจะได้สิทธิ์ครบ

หน้าเว็บของบอท (`/` ที่พอร์ต 3000 หรือพอร์ตที่ Render กำหนดผ่าน `PORT`) แสดงสถานะและเพลงที่กำลังเล่น ใช้เป็น URL ให้ cron-job.org / UptimeRobot ping ได้

## โฮสต์ตลอด 24 ชม. ฟรี บน Render

Free Web Service ของ Render จะหลับหลังไม่มี request เข้ามา 15 นาที (การเชื่อมต่อ Discord ของบอทเป็นขาออก ไม่นับว่าเป็น request เข้า) วิธีกันหลับ:

1. ใช้ `/health` (มีอยู่แล้วใน `keep-alive.js`) เป็นปลายทางให้ ping
2. ไปตั้งที่ [cron-job.org](https://cron-job.org) (ฟรี ไม่จำกัด) ให้ยิง GET ไปที่ URL ของบอทบน Render ทุก 10-14 นาที
3. เท่านี้บอทจะออนไลน์ตลอด ไม่ต้องกดต่ออายุเองรายสัปดาห์เหมือน Replit

โควตาฟรีของ Render คือ 750 ชั่วโมง/เดือน ซึ่งพอสำหรับรัน 1 เซอร์วิสตลอดทั้งเดือนพอดี (ไม่เกิน) ไม่ต้องกังวลเรื่องโดนตัด
